编程语言不限，可以使用 AI 辅助。

## 视频任务与交付

我们在做一个短视频自动裂变系统。第一步是把一条成品视频切成镜头片段，后面才能做打标、检索和重新组合。这次作业就是把这一步做出来。

给你 3 条美妆类短视频（1–3 分钟，见本材料包）。写一个程序，一次运行批量处理这 3 条视频，把每条视频划分为镜头片段。镜头边界由你判断，请在说明中简述判断依据。

1. 输出结果：给出每个镜头的起止时间和一张预览图，格式自定，无需另行导出视频。
2. 异常处理：考虑输入差异和处理失败；单条视频失败时，记录原因并继续处理其他视频。
3. 结果验证：展示一个实际切分结果，说明你如何检查它是否正确，并记录发现的问题。

提交可运行代码、运行方法和主要设计取舍。
