## 视频任务与交付

我们在做一个短视频自动裂变系统。第一步是把一条成品视频切成镜头片段，后面才能做打标、检索和重新组合。这次作业就是把这一步做出来。

给你 3 条美妆类短视频（1–3 分钟，见本材料包）。写一个程序，一次运行批量处理这 3 条视频，把每条视频划分为镜头片段。镜头边界由你判断，请在说明中简述判断依据。

1. 输出每个镜头的开始时间、结束时间，以及一张预览图；不强制导出独立视频文件。
2. 输出格式由你定，并说明为什么这样设计。
3. 考虑输入差异与异常情况，例如分辨率、帧率、是否有音轨，以及单条视频处理失败。
4. 展示你如何检查切分结果，指出一个处理得较好或仍不理想的片段，并说明原因。

提交可运行代码与说明，包含运行方法、输出示例和设计取舍。
